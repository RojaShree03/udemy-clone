# Udemy Clone

A responsive Udemy website clone built using HTML and CSS. This project recreates the main layout of Udemy, including the navbar, search bar, category menu, promotional banner, recommended courses, recommended topics, popular courses, and footer.

## Project Purpose

This project was created for **practice purposes** to improve my front-end development skills, especially in:

- HTML structure and semantic elements
- CSS styling
- Flexbox layout
- Responsive web design
- Media queries
- Hover effects
- Creating reusable course card layouts

## Features

- Responsive navigation bar
- Search bar
- Course categories
- Promotional banner
- Recommended courses section
- Recommended topics section
- Popular courses section
- Responsive course cards
- Responsive footer
- Hover effects
- Mobile, tablet, and desktop responsive design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Font Awesome
- Google Fonts


##Practice Project

This is a **practice project** created to learn and strengthen my front-end development skills. It is not an official Udemy website and is created only for educational purposes.

## Note

This project is a static website built using HTML and CSS. No backend or JavaScript functionality has been implemented.
